# مستندات پروژه Content Producer

این پروژه یک سامانه تولید و انتشار خودکار محتوا است. سامانه با استفاده از هوش مصنوعی، محتوای روزانه را از روی موضوعات و منابع تعریف‌شده تولید می‌کند و پس از کنترل کیفیت، آن را در وب‌سایت وردپرسی و اینستاگرام منتشر می‌کند.

## هدف پروژه

- کاهش زمان لازم برای ایده‌پردازی، نگارش و انتشار محتوای روزانه
- ایجاد لحن و ساختار یکپارچه در کانال‌های مختلف
- انتشار قابل برنامه‌ریزی در وردپرس و اینستاگرام
- نگهداری سوابق تولید، بازبینی و انتشار محتوا
- فراهم کردن امکان تأیید انسانی پیش از انتشار

## اصول اولیه

1. انتشار محتوا باید قابل ردیابی و قابل توقف باشد.
2. اطلاعات ورود، توکن‌ها و کلیدهای API نباید داخل کد یا مخزن Git ذخیره شوند.
3. خروجی هوش مصنوعی پیش از انتشار باید از نظر کیفیت، صحت و محدودیت‌های هر پلتفرم بررسی شود.
4. سامانه باید از انتشار تکراری جلوگیری کند.
5. در نسخه‌های اولیه، تأیید انسانی به‌صورت پیش‌فرض فعال خواهد بود.
