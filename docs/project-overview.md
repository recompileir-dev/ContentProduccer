# تعریف و محدوده پروژه

## مسئله

تولید منظم محتوا برای وب‌سایت و شبکه‌های اجتماعی فقط نوشتن متن نیست. برای هر
انتشار باید موضوع تازه انتخاب شود، درباره آن تحقیق شود، مقاله نوشته شود، تصویر
شاخص آماده شود، متن شبکه‌های اجتماعی ساخته شود و در چند کانال منتشر شود. انجام
دستی این چرخه زمان‌بر است و احتمال خطا، تکرار موضوع و ناهماهنگی میان کانال‌ها را
زیاد می‌کند.

## راهکار فعلی

Content Producer یک Worker سرویس با .NET است که در زمان مشخص یا با دستور دستی
اجرا می‌شود. سرویس با کمک Provider انتخاب‌شده مقاله فارسی تولید می‌کند، در صورت
نیاز تصویر شاخص می‌سازد، مقاله را در وردپرس منتشر می‌کند و خلاصه مطلب را به
تلگرام و در صورت وجود تصویر به اینستاگرام می‌فرستد.

## کاربران اصلی

- مدیر محتوا: تعیین سیاست محتوا، موضوعات مجاز و کیفیت خروجی
- مدیر سایت: تنظیم وردپرس، دسته‌بندی، سئو و مسیر انتشار
- مدیر شبکه‌های اجتماعی: تنظیم تلگرام، اینستاگرام و قالب کپشن
- مدیر سیستم: تنظیم Docker، متغیرهای محیطی، زمان‌بندی، لاگ و سکرت‌ها

## قابلیت‌های نسخه فعلی

- اجرای زمان‌بندی‌شده روزانه با `SchedulerAgent`
- اجرای دستی با دستور `run-once` برای تست لوکال یا اجرای فوری
- تولید مقاله با `OpenAI`، `Groq` یا داده نمونه `Fixture`
- پیدا کردن یا تولید تصویر شاخص با `SourcePageImages`، `OpenAI`، `Pollinations` یا `Fixture`
- امکان اجرای کامل بدون تصویر با `ImageProvider: None`
- پرامپت‌های قابل ویرایش برای مقاله و تصویر
- پرامپت اختصاصی برای Groq به‌خاطر رفتار متفاوت مدل‌ها
- استفاده از Groq در دو مرحله research و writing
- fallback برای خطاهای JSON در Groq
- ساخت مقاله در وردپرس به‌صورت پیش‌نویس از طریق REST API
- آپلود فقط یک تصویر برای هر مقاله و استفاده از آن به‌عنوان تصویر شاخص
- درج تصویر در ابتدای محتوای وردپرس وقتی تصویر وجود دارد
- ارسال excerpt، دسته‌بندی، لینک داخلی و داده‌های پایه سئو به وردپرس
- اعتبارسنجی اتصال وردپرس و دسته‌بندی قبل و بعد از انتشار
- انتشار خلاصه و لینک مطلب در تلگرام طبق تنظیمات انتشار
- انتشار تک‌تصویری در اینستاگرام وقتی تصویر عمومی از وردپرس وجود داشته باشد
- تست بدون LLM با fixture
- استقرار با Docker Compose روی سرور لینوکس

## خارج از محدوده نسخه فعلی

- دیتابیس، تاریخچه jobها و جلوگیری قطعی از تکرار موضوع
- پنل مدیریتی و مرحله تأیید انسانی قبل از انتشار
- صف، retry پیشرفته و idempotency کامل برای جلوگیری از پست تکراری
- تحلیل عملکرد محتوا و پیشنهاد خودکار استراتژی
- پاسخ‌گویی به دیدگاه‌ها و پیام‌ها
- تولید ویدئو یا Reel
- انتشار در لینکدین، X یا سایر پلتفرم‌ها

## نیازمندی‌های غیرعملکردی

- امنیت: نگهداری API keyها، توکن‌ها و پسوردها فقط در environment variable یا فایل‌های ignored
- توسعه‌پذیری: امکان افزودن Provider جدید برای متن، تصویر یا کانال انتشار
- کنترل هزینه: امکان انتخاب Groq، SourcePageImages، Pollinations، Fixture یا `ImageProvider: None` برای کاهش هزینه تست
- مشاهده‌پذیری: لاگ کافی برای تشخیص خطاهای API و انتشار
- کیفیت محتوا: پرامپت‌های قابل تنظیم، حداقل طول مقاله و کنترل موضوعات مجاز
- استقرارپذیری: اجرای یکسان روی لوکال و سرور لینوکس با Docker

## معیارهای موفقیت فعلی

- اجرای موفق Worker با scheduler یا `run-once`
- تولید مقاله معتبر فارسی با ساختار JSON قابل parse
- ساخت موفق پیش‌نویس مقاله در دسته‌بندی درست وردپرس
- ارسال لینک مطلب به تلگرام طبق تنظیمات انتشار
- انتشار اینستاگرام فقط زمانی که تصویر آماده و عمومی وجود دارد
- امکان تست مسیر وردپرس/تلگرام با fixture بدون هزینه LLM
