# جریان تولید و انتشار محتوا

## جریان فعلی اجرای روزانه

1. `SchedulerAgent` در ساعت تنظیم‌شده یا دستور `run-once` اجرای workflow را شروع می‌کند.
2. اگر انتشار وردپرس فعال باشد، اتصال WordPress REST API و دسته‌بندی validate می‌شود.
3. `ContentGeneratorService` Provider متن را از `ContentGeneration:LlmProvider` انتخاب می‌کند.
4. پرامپت مقاله از فایل پیش‌فرض یا override مخصوص Provider خوانده می‌شود.
5. Provider متن مقاله را به‌صورت JSON ساختارمند تولید می‌کند.
6. `GeneratedArticleParser` خروجی را parse و اعتبارسنجی می‌کند.
7. Provider تصویر از `ContentGeneration:ImageProvider` انتخاب می‌شود.
8. اگر Provider تصویر `OpenAI` یا `Fixture` باشد یک تصویر شاخص تولید/لود می‌شود.
9. اگر Provider تصویر `None` باشد workflow بدون تصویر ادامه پیدا می‌کند.
10. تصویر، در صورت وجود، مستقیماً در WordPress Media Library آپلود می‌شود.
11. مقاله در وردپرس منتشر می‌شود و لینک نهایی مطلب از پاسخ REST API خوانده می‌شود.
12. کپشن اینستاگرام و تلگرام از خلاصه مقاله و لینک وردپرس ساخته می‌شود.
13. اینستاگرام فقط وقتی تصویر عمومی وجود دارد منتشر می‌شود.
14. تلگرام با تصویر یا بدون تصویر پیام را در کانال ارسال می‌کند.

## خروجی مقاله

هر Provider متن باید JSON معتبر با این فیلدها برگرداند:

- `title`
- `articleHtml`
- `instagramCaption`
- `focusKeyphrase`
- `seoTitle`
- `metaDescription`
- `references`

فیلد `instagramCaption` فقط برای اینستاگرام استفاده نمی‌شود؛ خلاصه شبکه‌های
اجتماعی تلگرام هم از همین متن ساخته می‌شود.

## رفتار کانال‌ها

### وردپرس

- کانال اصلی انتشار است.
- مقاله در دسته‌بندی تنظیم‌شده منتشر می‌شود.
- اگر تصویر وجود داشته باشد، فقط یک تصویر آپلود می‌شود.
- تصویر هم featured media می‌شود و هم ابتدای محتوای مقاله قرار می‌گیرد.
- excerpt از `metaDescription` مقاله ساخته می‌شود.
- لینک‌های داخلی تنظیم‌شده به محتوا اضافه می‌شوند.

### تلگرام

- بعد از انتشار وردپرس، خلاصه و لینک مطلب به کانال ارسال می‌شود.
- اگر تصویر موجود باشد، پیام با `sendPhoto` ارسال می‌شود.
- اگر تصویر موجود نباشد، پیام متنی با `sendMessage` ارسال می‌شود.
- bot باید عضو کانال باشد و اجازه ارسال پیام داشته باشد.

### اینستاگرام

- بعد از انتشار وردپرس، تصویر عمومی وردپرس به Instagram Graph API داده می‌شود.
- کپشن شامل خلاصه و لینک مطلب است.
- اگر تصویر وجود نداشته باشد، انتشار اینستاگرام skip می‌شود.

## حالت‌های اجرای رایج

### اجرای کامل با OpenAI

```json
{
  "ContentGeneration": {
    "LlmProvider": "OpenAI",
    "ImageProvider": "OpenAI"
  }
}
```

### تولید مقاله با Groq و بدون تصویر

```json
{
  "ContentGeneration": {
    "LlmProvider": "Groq",
    "ImageProvider": "None"
  }
}
```

در این حالت وردپرس text-only منتشر می‌شود، تلگرام پیام متنی می‌فرستد و
اینستاگرام skip می‌شود.

### تست بدون API با fixture

```bash
dotnet run --project src/ContentProducer.Worker -- run-once --use-fixture --skip-instagram
```

این دستور مقاله و تصویر نمونه را لود می‌کند و برای تست وردپرس و تلگرام مناسب است.

## مدیریت خطا در نسخه فعلی

- خطای اتصال وردپرس قبل از تولید محتوا مشخص می‌شود.
- خطای دسته‌بندی وردپرس باعث توقف اجرا می‌شود تا پست بدون دسته‌بندی منتشر نشود.
- اگر Groq در مرحله research خطای 413 بدهد، با تنظیم پیش‌فرض اجرا بدون research ادامه پیدا می‌کند.
- اگر Groq خروجی JSON نامعتبر بدهد، یک fallback writer امتحان می‌شود.
- اگر تصویر تولید نشود، کانال‌هایی که به تصویر نیاز دارند skip می‌شوند.

## محدودیت‌های باقی‌مانده

- retry کامل و idempotency وجود ندارد؛ اگر مرحله‌ای بعد از انتشار وردپرس خطا بدهد، ثبت پایدار برای ادامه از همان نقطه نداریم.
- جلوگیری قطعی از تکرار مقاله نیاز به دیتابیس و تاریخچه موضوعات دارد.
- بازبینی انسانی قبل از انتشار هنوز به workflow اضافه نشده است.
