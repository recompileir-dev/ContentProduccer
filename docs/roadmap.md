# نقشه راه توسعه

## فاز 0: آماده‌سازی پروژه

- انتخاب زبان، فریم‌ورک و پایگاه داده
- تعریف ساختار مخزن و استانداردهای کدنویسی
- تنظیم مدیریت متغیرهای محیطی و اسرار
- ایجاد محیط توسعه و تست

## فاز 1: هسته تولید محتوا

- تعریف مدل‌های داده محتوا و وضعیت‌ها
- پیاده‌سازی ایجاد موضوع و پیش‌نویس
- اتصال به سرویس هوش مصنوعی
- نسخه‌بندی پرامپت‌ها
- ثبت تاریخچه اجرای مراحل

## فاز 2: کنترل کیفیت و بازبینی

- پیاده‌سازی قواعد اعتبارسنجی
- ایجاد جریان تأیید، رد و اصلاح محتوا
- جلوگیری از محتوای تکراری
- ثبت لاگ و اعلان خطا

## فاز 3: انتشار در وردپرس

- اتصال امن به WordPress REST API
- انتشار پیش‌نویس و نوشته
- آپلود تصویر شاخص
- ثبت شناسه و لینک نوشته
- مدیریت تلاش مجدد بدون ایجاد نوشته تکراری

## فاز 4: انتشار در اینستاگرام

- اتصال به Instagram Graph API
- آماده‌سازی کپشن و رسانه
- انتشار و ثبت شناسه رسانه
- مدیریت محدودیت نرخ و خطاهای API

## فاز 5: زمان‌بندی و عملیات

- ایجاد زمان‌بند روزانه
- داشبورد وضعیت محتوا و کارها
- مانیتورینگ، گزارش خطا و مصرف API
- تهیه نسخه پشتیبان و مستندات استقرار

## تصمیم‌های فنی مورد نیاز

- زبان و فریم‌ورک اصلی بک‌اند
- نوع پایگاه داده
- ابزار صف و زمان‌بندی کارها
- سرویس هوش مصنوعی و مدل‌های مورد استفاده
- روش تولید یا تأمین تصویر
- روش احراز هویت کاربران پنل
- محیط استقرار و Secret Manager
