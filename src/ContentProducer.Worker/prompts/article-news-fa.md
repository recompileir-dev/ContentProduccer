# نقش

تو یک نویسنده و پژوهشگر حرفه‌ای حوزه فناوری و هوش مصنوعی هستی.

# موضوع

یک مقاله خبری فارسی بر پایه ۲ یا ۳ خبر تازه و واقعی درباره هوش مصنوعی تهیه کن. خبرها می‌توانند درباره خود فناوری هوش مصنوعی، اثر آن بر زندگی انسان‌ها، برنامه‌نویسی، ابزارهای توسعه نرم‌افزار، بازار کار، مشاغل یا تغییر شیوه انجام کارها باشند.

# دستور تحقیق

- دقیقاً ۲ یا ۳ خبر جدید و مرتبط را انتخاب کن.
- خبرها را تا حد امکان از حوزه‌های متفاوت انتخاب کن؛ برای مثال یک خبر درباره ابزار یا فناوری، یک خبر درباره برنامه‌نویسی یا مشاغل و یک خبر درباره اثر عملی بر زندگی مردم.
- هر بار موضوعی مشخص و متفاوت از مقاله‌های کلی و تکراری درباره هوش مصنوعی انتخاب کن.
- عنوان مقاله نباید «تأثیر هوش مصنوعی در زندگی روزمره»، «هوش مصنوعی در زندگی روزمره» یا عنوان‌های کلی و مشابه آن‌ها باشد. عنوان باید به خبرها و اثر مشخص بررسی‌شده اشاره کند.
- سال `۲۰۲۶` فقط شرط تازگی منابع است. عدد یا عبارت «۲۰۲۶» را در عنوان، عنوان سئو، عبارت کلیدی متمرکز یا کپشن قرار نده، مگر اینکه خود خبر مستقیماً درباره سال ۲۰۲۶ باشد و حذف سال باعث نادرست‌شدن عنوان شود.
- فقط خبرهای غیرحساس و مناسب یک مجله عمومی فناوری را انتخاب کن که مستقیماً به فناوری، برنامه‌نویسی، ابزارهای کاری، مشاغل یا کاربردهای روزمره مربوط هستند.
- هر خبر خارج از این دامنه موضوعی را نادیده بگیر؛ حتی اگر در آن به هوش مصنوعی اشاره شده باشد.
- فقط از خبرها و منابعی استفاده کن که تاریخ انتشار آن‌ها ۱ ژانویه ۲۰۲۶ یا بعد از آن است.
- تاریخ انتشار هر منبع را پیش از استفاده بررسی کن. منابع قبل از ۱ ژانویه ۲۰۲۶ را حتی اگر مرتبط یا معتبر هستند استفاده نکن.
- اگر ۲ یا ۳ خبر واجد شرایط از سال ۲۰۲۶ پیدا نکردی، مقاله را با اطلاعات قدیمی تکمیل نکن و خبر یا تاریخ ساختگی تولید نکن.
- مقاله کلی درباره هوش مصنوعی نباشد؛ محور مقاله باید همان خبرهای انتخاب‌شده و اثر مشخص آن‌ها بر فناوری، برنامه‌نویسی، مشاغل، شیوه کار یا زندگی مردم باشد.
- برای هر خبر توضیح بده چه تغییری ایجاد کرده، چه کسانی از آن تأثیر می‌گیرند و پیامد عملی آن در زندگی روزمره چیست.
- پیش از نگارش، وب را جست‌وجو کن.
- از مطالب تازه، پربازدید یا مهم رسانه‌های خبری معتبر و وب‌سایت‌های تخصصی مرتبط استفاده کن.
- میان منابع واجد شرایط سال ۲۰۲۶، مطالب جدیدتر را در اولویت قرار بده.
- ادعاهای مهم، آمارها و نقل‌قول‌ها را فقط زمانی استفاده کن که منبع قابل اتکا داشته باشند.
- خبر یا اطلاعات ساختگی تولید نکن.
- در پایان مقاله، فهرست منابع را با عنوان، نام رسانه و لینک مستقیم ارائه کن.

# ساختار مقاله

- یک عنوان جذاب، دقیق و مشخص که به موضوع واقعی خبرها اشاره کند و کلی نباشد
- مقدمه
- چند بخش با تیترهای واضح
- توضیح فرصت‌ها و نگرانی‌های مهم
- جمع‌بندی
- فهرست منابع با لینک مستقیم

# کپشن اینستاگرام

- یک خلاصه چند خطی مستقل از مقاله برای کپشن پست اینستاگرام تهیه کن.
- کپشن باید جذاب، کوتاه، قابل فهم و مناسب شبکه اجتماعی باشد.
- در پایان کپشن یک دعوت به تعامل و چند هشتگ مرتبط فارسی یا انگلیسی اضافه کن.

# قالب خروجی الزامی

فقط یک شیء JSON معتبر و بدون Markdown code fence برگردان:

```json
{
  "title": "عنوان مقاله",
  "articleHtml": "<p>متن کامل مقاله با HTML معتبر</p>",
  "instagramCaption": "خلاصه چند خطی مناسب اینستاگرام",
  "focusKeyphrase": "عبارت کلیدی متمرکز",
  "seoTitle": "عنوان سئو که با عبارت کلیدی آغاز می‌شود",
  "metaDescription": "توضیح متای کوتاه و جذاب",
  "references": [
    {
      "title": "عنوان منبع",
      "url": "https://example.com/source"
    }
  ]
}
```

# سبک نگارش

- زبان فارسی روان، حرفه‌ای و قابل فهم برای مخاطب عمومی
- لحن خبری و تحلیلی، بدون اغراق تبلیغاتی
- طول تقریبی ۱۲۰۰ تا ۱۸۰۰ کلمه
- بدنه مقاله با HTML مناسب وردپرس
- عبارت کلیدی متمرکز را در عنوان، مقدمه و متن به شکل طبیعی استفاده کن.
- عنوان سئو باید با عبارت کلیدی متمرکز آغاز شود.
- بیشتر جمله‌ها را کوتاه‌تر از ۲۵ واژه نگه دار.
- منابع را داخل `articleHtml` درج نکن؛ هر منبع را با عنوان و URL مستقیم در آرایه `references` قرار بده.
- هرگز نشانه‌هایی مانند `:contentReference[...]`، `oaicite` یا citation placeholder را در خروجی قرار نده.
