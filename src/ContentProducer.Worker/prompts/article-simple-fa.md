# موضوع

یک مقاله کوتاه فارسی درباره تاثیر هوش مصنوعی در زندگی روزمره بنویس.

# نیازمندی‌ها

- متن برای مخاطب عمومی ساده و روان باشد.
- مقاله حدود ۴۰۰ تا ۶۰۰ کلمه باشد.
- چند نمونه کاربردی از استفاده هوش مصنوعی در کار، آموزش و زندگی روزمره ارائه کن.
- از ادعاهای آماری، خبرهای روز و اطلاعاتی که نیاز به جست‌وجوی وب دارند استفاده نکن.
- برای مقاله یک عنوان مناسب بنویس.
- یک خلاصه کوتاه و جذاب برای شبکه‌های اجتماعی آماده کن.
- بدنه مقاله را با HTML مناسب وردپرس تولید کن.

# قالب خروجی

فقط یک شیء JSON معتبر با این فیلدها برگردان:

```json
{
  "title": "عنوان مقاله",
  "articleHtml": "<p>متن کامل مقاله با HTML معتبر</p>",
  "instagramCaption": "خلاصه کوتاه مناسب شبکه‌های اجتماعی",
  "focusKeyphrase": "عبارت کلیدی متمرکز",
  "seoTitle": "عنوان سئو که با عبارت کلیدی آغاز می‌شود",
  "metaDescription": "توضیح متای کوتاه و جذاب",
  "references": []
}
```

# الزامات سئو

- عبارت کلیدی متمرکز را در عنوان، مقدمه و چند بخش متن به شکل طبیعی استفاده کن.
- عنوان سئو باید با عبارت کلیدی متمرکز آغاز شود.
- مقدمه باید شامل عبارت کلیدی متمرکز باشد.
- جمله‌ها را کوتاه و خوانا نگه دار و بیشتر جمله‌ها کمتر از ۲۵ واژه باشند.
- از نشانه‌هایی مانند `:contentReference[...]` یا citation placeholder در خروجی استفاده نکن.
